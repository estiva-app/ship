# Design Tokens

Ship is **token-driven** — components reference these tokens, never raw hex.
Every swatch below reads a live CSS variable, so it reflects the theme selected
in the **Theme** toolbar. The names are the ones you use in code: a colour token
`bg-surface` is the Tailwind class `bg-bg-surface`; a type token `body-2` is
`text-body-2`.

**The names are shared with Peek and, soon, with every Estiva app** through the
`@estiva/ui` package. **The values are Ship's own theme.** The palette shown
here is provisional — today's Ship colours mapped onto the shared names so there
is something to look at — and will be replaced by Ship's designed palette in its
own pass. Changing a value in `src/index.css` changes every swatch on this page
and every component built on it.

> Source of truth: `src/index.css` (the values, per theme) and
> `tailwind.config.js` (the names, plus the type / radius / shadow scales).

## Typography

Font family is **Geist**. The ramp pairs headings, body, and component-specific
sizes. Component tokens (`btn-*`, `input-*`, `chip`) are deliberately explicit —
in shared components prefer arbitrary values (`text-[12px] leading-[12px]`),
because tailwind-merge silently drops a custom size class that is followed by a
`text-{colour}` class.

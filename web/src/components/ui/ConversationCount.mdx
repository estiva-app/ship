# ConversationCount

How much has been said about a file: a speech-bubble glyph and a number.

<Canvas of={ConversationCountStories.Conversations} />

## When

- On a row or a card that names a file — an issue row, a foreign object card.
- Before the app chip, which is the order an issue row keeps: what is said
  about the file, then where it lives.

## When not

- At zero. It draws nothing, and that is deliberate.
- Never as a hand-written glyph and class string. The same class string twice
  is a component.

## How

```tsx
import { ConversationCount } from '@/components/ui/ConversationCount'

<ConversationCount count={issue.conversations ?? 0} unit="conversation" />
```

- `unit` is the caller's, because the number is not always the same thing: an
  issue row counts *conversations*, threads at the root; a foreign file counts
  *comments* addressed to it, replies included. **It changes nothing on screen**
  — it is the sentence a screen reader is given (`7 conversations`, `23
  comments`), which is why there is no second story for it.

## What it owns

- **The zero rule.** A zero is a real answer on the wire — "nothing is
  addressed to this file" — but a column of noughts says less than their
  absence.
- **The plural**, and the sentence a screen reader is given, which is the unit
  spelled out rather than a bare number beside a picture.

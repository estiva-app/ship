# Centred

The reading column of a page's Overview: 768px, centred, 52px under the tab
row (an issue's page has no tab row since ONE-6, step 4d).

**Seen in** Pages/In the shell: Project, Project Overview Panel, Issue, Issue
Overview Panel.

## When

- For a page that is read top to bottom: the title, its fields, the description.

## When not

- For a list that needs the width — the Issues tab's **IssuesTable** and
  **Board** take the whole column.

## How

```tsx
import { Centred } from '@/components/layout/ReadingColumn'

{tab === 'overview' && <Centred gap="block">…</Centred>}
```

## What it owns

- **The width and the gap under the tabs** (Katerina, 29 September: Linear's
  width, measured; 52px), so a project's Overview and an issue's page cannot
  drift apart.

# AppSection

A section the app adds to a page — Conversations, Mentioned in, History,
Related — with its title in the type ramp's h4.

**Seen in** Pages/In the shell: Project, Project Activity, Issue Activity.

## When

- For a list the app draws, under the description or on the Activity tab.

## When not

- For a heading somebody typed: that is the description's own heading, drawn
  by **LiveHeader**. A line above Related keeps the two apart.

## How

```tsx
import { AppSection } from '@/components/layout/ReadingColumn'

<AppSection title="Conversations">
  <ThreadList … />
</AppSection>
```

## What it owns

- **The title's size**: 16px semibold (Katerina, 29 September: 12px, then 14px,
  were too small), and no count beside it.

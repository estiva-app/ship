# MessagePart

Wraps a part of another file shown in a message, so a click on a link inside
it is routed as a chip's is: another app's address opens in a new tab.

**Seen in** none: it draws nothing of its own, only the part inside it, whose
stories are Primitives/PartCard.

## When

- Around a `PartCard` in a message: a part the message shows under its text,
  or the block a comment is about, above it.

## When not

- A link of the message's own → **MessageText** draws its chip, row or card
  and routes their clicks already.

## How

```tsx
import { MessagePart } from '@/components/ui/MessageLinks'

<MessagePart>
  <PartCard address={part.address} block={part.block} />
</MessagePart>
```

## What it owns

- **Another app's link in a new tab, with `noopener`**: a manifest anyone may
  publish wrote it. Ship's own links are the kit's, through `AppProvider`.

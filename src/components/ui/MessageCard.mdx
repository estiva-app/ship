# MessageCard

The card a message carries for one file it names (SPEC §13.6.2): the package's
card, filled with what Ship reads about that file.

**Seen in** no story: a card draws a file read from the relay, which the stories' fake relay does not answer; `ThreadList.cards` and `ThreadList.embeds` draw it in tests.

## When

- A sent message's card, under its text (`MessageText`), with ✕ for its author.
- The card a comment will be sent with, in the comment box under its text and
  files while it is written or edited (`ConversationBox`, COMM-7), where the
  box's own ✕ takes it off.
- The card its writer chose in a description, in its lone link's place
  (`DescriptionLink`).

## When not

- A file named mid-sentence → its chip, **Reference**.
- One block of a file → **PartCard**.

## How

```tsx
import { MessageCard } from '@/components/ui/MessageLinks'

<MessageCard uri={card.reference} object={resolved[card.reference]} onRemove={removeCard} />
```

## What it owns

- **The file's live fields**, changed from the card and read back, since the
  relay is the authority on whether a change happened (Decided 16 Oct).
- **Never blank**: loading keeps the card's last height; a file it cannot
  read, or a read that failed (a busy relay, the network), draws the
  not-available row, and a failed read is asked again quietly with the page's
  refresh, never remembered as not available.
- **The comment count's dot**, shown only for a member with something unread.
- **`words`**: its values as words, no pickers, where the reader cannot act —
  a closed conversation (an archived file's), a description only read. A card
  in a description being written keeps its pickers (Katerina, 30 Oct).
- **`compact`**: an old message's row, as it drew before the kit.

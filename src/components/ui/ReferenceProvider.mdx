# ReferenceProvider

Hands an editor the page's resolved references and its names, so a pointer
typed or pasted into it is drawn as the thing it names.

**Seen in** Pages/Title and description: Default; Inputs/Message box: New Conversation.

## When

- Around every editor that can hold a `nostr:` pointer — the description and
  the message box.

## When not

- Around a reading surface → **RichText** takes `resolved` and `nameOf` itself.

## How

```tsx
import { ReferenceProvider } from '@/components/ui/editorSchema'

<ReferenceProvider value={{ resolved, nameOf }}>
  <EditorContent editor={editor} />
</ReferenceProvider>
```

## What it owns

- **One answer per page**: the references are resolved once by the page and
  every editor reads them, so one object is never drawn in two states.

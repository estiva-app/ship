# Reference

A person named in text — a `nostr:npub` reference — as the package's person
chip, with the name the workspace directory gives. What stays of Ship's own
chip: a file or a message named in text is the kit's **LinkChip**, through
**MessageChip**, in a box being written in too (Katerina, 30 Oct).

<Canvas of={ReferenceStories.Person} />

## When

- A person a body names, wherever the parser says a run is a `nostr:npub`
  reference: a sent message, a description, a box being written in.
  **MessageChip** hands a person here itself.

## When not

- A file or a message → **MessageChip** (the kit's LinkChip): its key, its
  title cut short, its status as its mark.
- Never pattern-match a name back out of text: `@Ada` typed as words stays
  words.

## How

```tsx
import { Reference } from '@/components/ui/Reference'

<Reference uri={run.reference} nameOf={nameOf} urgent={message.urgent} />
```

## What it owns

- **The directory's name**: `@Ada Lovelace`, in the urgent tone for someone
  the message names urgently (CON-24).
- **Never blank, never the whole key**: somebody the directory cannot name is
  a short key, quiet, with the whole address on hover (§13.1).
- **A label, not a link**: Ship has no page for a person.

# MessageChip

A link to a file or a message in a sentence: the package's chip, filled with
what Ship reads about that file, or a person's chip for an `npub`.

**Seen in** no story: a chip draws a file read from the relay, which the stories' fake relay does not answer; `MessageText` and `LiveHeader` draw it in tests.

## When

- A reference in a sent message's text (`MessageText`).
- A link in a sentence of an issue's or a project's description (`DescriptionLink`, WBD-7).
- A link in a box being written in, pasted or kept from an edit (`ConversationBox`), with `preview={false}` and `follows={false}`: one chip look in every box (Katerina, 30 Oct).
- A link inside one block of another file, or another app's text (`ShipRichText`).

## When not

- A line that is only a link → **MessageRow**.
- The card its writer chose → **MessageCard**.
- A person → it hands an `npub` to **Reference** itself.

## How

```tsx
import { MessageChip } from '@/components/ui/MessageLinks'

<MessageChip uri={uri} object={resolved[uri]} nameOf={nameOf} preview={!editing} opensAt={href} />
```

## What it owns

- **The hover card**, off with `preview={false}`: in a list of previews, in a description being edited, where a click is the chip menu's, and on a chip whose file's card is already under the same message, which the hover card would cover (Katerina, 30 Oct).
- **Where it opens**: the URL it was written as, so a link to one block opens there (WBM-11). With `follows={false}` a click opens nothing: in a box, a click is not a way out of the draft.

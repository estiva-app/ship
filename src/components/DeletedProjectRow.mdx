# DeletedProjectRow

A deleted project or issue in the Archived view's Deleted filter: its title,
who deleted it and when, and Restore.

**Seen in** *Pages*: Projects → Archived → Deleted (ALO-4), and Issues →
Archived → Deleted (ISS-5).

## When

- **A deleted file listed for restoring**: a project or an issue whose
  `deleted` field is set (SPEC §6.5), with `Deleted by QA-1 · Today` in the
  app's words.

## When not

- **An archived file**: it keeps its own row (`ProjectRow`, `IssueList`),
  since archiving hides it without deleting it.
- **A deleted file's own page**: the page shows `DeletedNotice` with Restore.

## How

```tsx
<DeletedProjectRow href={href} title={title} deleted={`Deleted by ${who} · ${when}`} onRestore={restore} />
```

## What it owns

- The trash icon, the title as a link that opens the file, and the caption.
- Restore, which waits for `onRestore` before it can be pressed again.

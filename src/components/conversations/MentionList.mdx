# MentionList

"Mentioned in": conversations elsewhere that name this object, each under a
line saying where it lives — the sidebar's icon for a project or an issue, and
its name.

**Seen in** — *Pages/In the shell*: **Issue Overview Panel** and **Project
Overview Panel**.

## When

- In the **OverviewPanel**, under its "Activity" heading, in the column beside
  the page where the comments are when it is hidden (ONE-6, step 4d).

## When not

- For the object's own conversations → **ThreadList**. A thread about this
  object belongs there, and only a relation belongs here.

## How

```tsx
import { MentionList } from '@/components/conversations/ThreadList'

<MentionList items={activity} loading={loading} truncated={activityTruncated} about={about} nameOf={nameOf} />
```

- The props are production's `ActivityProps`. Read-only, Peek's way (PEE-48):
  no reply, reaction, edit or delete here; a press opens the page it was said
  on, when that page is Ship's.

## What it owns

- **The place line**, in words for a screen reader ("Mentioned in" is SPEC
  §6.4's phrase) and a mention drawn quieter than a sub-file's thread (CON-9).
- **Saying what it could not see**: the horizon, and that conversations in
  Folders this reader cannot read are absent without being counted.

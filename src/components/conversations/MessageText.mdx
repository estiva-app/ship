# MessageText

A message's text with its links, then the cards its author chose and the parts
it shows, drawn by the kit and by the rule Peek's messages follow.

**Seen in** Conversations/Conversations: Default, Mentioned In.

## When

- The body of a comment or a reply (`ThreadList`, the Activity tab, "Mentioned
  in").

## When not

- A description → **LiveHeader**, whose links draw by the document rule
  (**DescriptionLink**): the card its writer chose, in the row's place.
- A message listed as a file (Related, a Folder) → **ForeignObject**, the kit's
  row of its writer's words.

## How

```tsx
import { MessageText } from '@/components/conversations/MessageText'

<MessageText body={message.body} embeds={message.embeds} parts={message.parts} resolved={resolved} here={about} between={<Attachments files={message.files} />} />
```

## What it owns

- **Where a link sits decides how it draws** (record
  a-link-on-words-counts-toward-the-card): a chip in a sentence, the
  file's row on a line that is only its link, nothing on the line of a file
  whose card or part is under the message. A person or a Folder alone stays a
  chip.
- **No card for the file the conversation is on** (`here`, WID-3): its link
  stays where it was written.
- **A bare app link reads as its file's link** only once what it names has
  come back and can be read; otherwise it stays the URL as written.
- **No hover card on a chip whose file's card is under the message**, which
  it would cover (Katerina, 30 Oct).
- **`words`**: its cards' values as words where nobody can write here (an
  archived file's conversation, signed out).

# EditedCaption

Who edited a row's file last and when, as "Katerina, 2h ago", in its own
column on an initiative's page. Hidden on a phone.

**Seen in** *Pages*: an initiative's page, on each Leaf document (TOPI-8).

## When

- **A document row** on an initiative's page, with the label `editedLabel`
  builds: the first name and Ship's `ago()`.

## When not

- **An issue or a project row**: `WorkList`, whose Updated column says it for
  an issue, and which shows a project's lead and progress.
- **An issue's or a project's own page**: its History says who changed what.

## How

```tsx
{edited && <EditedCaption edited={edited} />}
```

## What it owns

- The column's width, so issues' and documents' captions line up.
- Truncating a long name, and leaving it out on a phone.
